# Shumi.space 🚀❤️‍🔥

**Shumi.space** — приложение для поиска друзей и единомышленников на основе общих хобби и интересов, работающее в формате Telegram Mini App.

## 🎯 Концепция проекта

Когда люди оказываются в новом сообществе, где они не знакомы друг с другом, но вынуждены взаимодействовать, им трудно быстро находить тех, с кем действительно есть общие интересы. **Shumi** решает эту проблему через систему **неймспейсов** — тематических сообществ, объединяющих людей по интересам.

### Ключевая идея
Переход от абстрактного глобального поиска знакомств к осмысленному взаимодействию внутри тематических пространств (школьная параллель, летний лагерь, научная конференция и т.д.).

## 🆕 Что нового в этом семестре

### Полная переработка технологической платформы
- ✅ **Миграция на Go + PostgreSQL** – переход с PocketBase на полноценный backend на Go с СУБД PostgreSQL для лучшей масштабируемости
- ✅ **Векторный поиск** – внедрен ML-пайплайн с использованием pgVector и Ollama (Jina AI Embeddings v4) для семантического поиска по интересам
- ✅ **Telegram Bot** – разработан бот для создания неймспейсов в группах с QR-кодами для приглашений

### Новые функции
- ✅ **Неймспейсы** – изоляция сообществ, администрирование, приглашения через бота
- ✅ **Улучшенная регистрация** – добавлен слайдер-тест для точного определения интересов
- ✅ **Расширенная визуализация** – график схожести по каждому интересу, показ процента совпадения
- ✅ **Бесконечная лента** – рекомендации на основе векторного поиска с динамическим ранжированием
- ✅ **Переход к профилям** – возможность просмотра детальной анкеты пользователя

### Frontend-обновления (Svelte + TypeScript)
- ✅ Полный переход на новый backend API
- ✅ Внедрение TanStack Query для кэширования и синхронизации состояния
- ✅ Рефакторинг кода: выделение переиспользуемых компонентов и хуков
- ✅ Оптимизация производительности, предотвращение лишних рендеров

## 👤 Целевая аудитория
- Подростки и молодежь (14–35 лет)
- Активные пользователи Telegram и социальных сетей
- Имеют хобби или ищут вдохновение
- Хотят самовыражения и общения с единомышленниками
- Проживают в России и странах СНГ

## 🤔 Проблема, которую решает продукт

1. **Отсутствие аудитории** в традиционных приложениях для знакомств по интересам
2. Сложность быстрого знакомства в новых сообществах (школа, лагерь, конференция)
3. Образование замкнутых микрогрупп, изоляция части участников
4. Потеря потенциально ценных знакомств из-за медленного взаимодействия

## 📈 Актуальность

По статистике ВЦИОМ:
- **81%** россиян имеют хобби (среди молодежи 18-35 лет — **85%**)
- **44%** молодежи до 35 лет пользуются онлайн-знакомствами (рост за 6 лет)
- **42%** испытывают потребность в поиске друзей по интересам
- **76%** интернет-пользователей активно читают чаты с разной периодичностью
- **56%** молодежи активно общаются с единомышленниками

## 📊 Конкурентный анализ

- **Random Coffee** – случайные встречи 1 на 1, слабая релевантность подборов
- **Lunchclub** – профессиональный нетворкинг, не работает в РФ
- **Сетка** – профсоцсеть для IT-специалистов
- **Teams/Slack Coffee Apps** – корпоративные инструменты

**Shumi** – единственное решение с неймспейсами в Telegram Mini App, адаптированное под российский рынок.

### Для пользователей
- 📝 Создание анкеты с гибкой кастомизацией через виджеты

- 📊 Визуализация схожести интересов (график + проценты)

### Для создателей сообществ
- 🏢 Создание неймспейсов через Telegram-бота в группах

## 💾 Технологический стек

### Frontend
- **Framework:** SvelteKit + Vite
- **Язык:** TypeScript
- **State Management:** TanStack Query
- **Стили:** Tailwind CSS + shadcn/ui
- **Аутентификация:** Telegram WebApp

### Backend
- **Язык:** Go
- **БД:** PostgreSQL + pgVector
- **API:** REST (документация: OpenAPI/Swagger)
- **ORM:** GORM
- **Middleware:** собственная аутентификация

### ML & Рекомендации
- **Векторизация:** Ollama + Jina AI Embeddings v4
- **Векторный поиск:** pgVector (косинусное сходство)
- **Алгоритм:** динамическое ранжирование с перемешиванием

### Интеграции
- **Кэширование внешних API:** Fastify (Node.js)
- **Платформы:** Twitch, Steam, VK, YouTube
- **Telegram Bot:** python-telegram-bot + QR-коды

### DevOps
- **Контейнеризация:** Docker + Docker Compose
- **CI/CD:** Coolify (автоматический деплой)
- **Хостинг:** VPS с облачной инфраструктурой

- Node.js 18+

### Установка

```bash
# Клонирование репозитория
git clone https://github.com/arizona-bebras/hobby-match.git
cd hobby-match

# Frontend
npm install
npm run dev

# Backend
cd backend
go mod download
go run cmd/main.go

# Telegram Bot
cd bot
pip install -r requirements.txt
python main.py

# Кэширующий сервис
cd caching
npm install
node index.js

# Или через Docker
docker-compose up -d
```
